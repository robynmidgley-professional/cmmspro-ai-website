# How data is handled

CMMSPro.AI is built privacy-first. Patient information is entered anonymously — no patient names or identifiable information are collected. Images are uploaded anonymously and only with the patient's consent. The system is not designed to retain patient data between sessions; the session data is not held once the session ends.

This architecture is intended to support therapists' obligations under privacy regimes such as HIPAA and POPIA.
